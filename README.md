# ⏰ Digital Clock

A simple and responsive **Digital Clock Web Application** built using **HTML, CSS, and JavaScript**. The clock displays the current time in real-time with a clean and user-friendly interface.

## 🚀 Live Demo

🔗 **[View Digital Clock](https://purvadere05-eng.github.io/Digital-Clock/)**

> Note: The live demo will work after enabling GitHub Pages for this repository.

## ✨ Features

- 🕐 Displays the current time in real-time
- ⏱️ Shows hours, minutes, and seconds
- 🔄 Automatically updates every second
- 🎨 Clean and simple user interface
- 📱 Responsive design
- ⚡ Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page
- **CSS3** – Styling and layout
- **JavaScript** – Clock functionality and real-time updates

## 📂 Project Structure

Digital-Clock/
- index.html
- README.md

## 💡 How It Works

The Digital Clock uses JavaScript's `Date()` object to get the current system time.

The time is updated every second using JavaScript so that the displayed hours, minutes, and seconds remain accurate.
